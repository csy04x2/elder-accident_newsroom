# S04 편집장 승인 비밀번호 설정

S04의 승인·보류는 별도 테이블 없이 기존 `articles`의 검수 상태·검수 해시·편집장 기록을 사용합니다.

로컬 PowerShell에서 `python scripts/create_editor_password.py`를 실행하여 편집장 비밀번호(12자 이상)를 두 번 입력하세요. 화면에 표시된 `EDITOR_PASSWORD_HASH=...` 전체를 이 저장소 루트의 `.env`에 추가합니다. 입력한 원래 비밀번호는 저장하거나 출력하지 않습니다.

S04의 '자동 사실 검수 실행'은 Python 수치·근거 검사와 OpenAI 문맥 검사를 결합합니다. 검수 실패나 AI API 오류는 PASS가 아닙니다. 승인할 때는 4개 체크리스트, 편집장 비밀번호, 최신 기사 제목·본문·연결 근거의 해시 일치를 서버 측 DB 트랜잭션에서 다시 검사합니다.

비밀번호 해시는 로컬 시연을 위한 단일 편집장 인증입니다. 공개 배포 전에는 별도 인증/세션 권한 및 접근 제어가 필요합니다. `EDITOR_PASSWORD_HASH`를 GitHub에 커밋하지 마세요.
