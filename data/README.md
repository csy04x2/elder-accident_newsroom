# 데이터 연결 위치

기본값은 저장소와 같은 상위 폴더에 있는 `elder_accident/data/processed/`입니다.
별도 위치에 있다면 `.env`의 `DATA_DIR`에 그 폴더 경로를 입력하세요.

이번 S01 화면은 기존 [elder_accident](https://github.com/csy04x2/elder_accident)의 가공 CSV를 **읽기 전용**으로 연결합니다. 데이터 파일은 새 저장소에 복제하지 않습니다.

필수 파일:
- `01_자치구연도_패널.csv`
- `03_다발지역_서울.csv`
- `05_보호구역_경계.csv`
- `06_다발지역_보호구역_연결.csv`

통계 기준일과 마지막 자동 수집 시각은 다릅니다. 자동 업데이트가 구현되기 전에는 기존 데이터의 선택 연도만 표시합니다. API 경계 자료가 지정 시설 전체를 포괄하지 않을 수 있으며 사고다발지역 개수를 개별 사고 수로 읽지 않습니다.
